BMI online com Supabase (partilhado) + instalável no telemóvel e com modo offline

Os nomes dos menus podem mudar: se algo não bater, siga a lógica.
1) supabase.com > New project (guarde a palavra-passe da base de dados; escolha uma região).
2) SQL Editor > New query > cole o conteúdo de setup.sql > Run.
3) Authentication > Users > Add user (e-mail + palavra-passe; marque "Auto Confirm"). Crie uma conta por pessoa.
   Em Authentication > Sign In / Providers, DESACTIVE o registo livre de novos utilizadores ("Allow new users to sign up").
   Depois, no SQL Editor, execute as 2 linhas comentadas no fim do setup.sql: dar acesso a todos e tornar administradores os escolhidos.
4) Project Settings > API (ou "Data API"): copie o Project URL e a chave "anon public" para o ficheiro supabase-config.js.
5) GitHub: substitua os ficheiros do repositório por estes (Add file > Upload files) e faça Commit. O Pages actualiza em minutos.
6) Telemóvel: abra o link, entre com e-mail e palavra-passe, e use "Adicionar ao ecrã inicial".

Offline: o app guarda uma cópia no aparelho e uma fila de alterações; envia tudo quando houver internet (vence a última alteração).
A etiqueta do topo mostra online/offline e quantas alterações faltam enviar. Antes de sair da conta, ligue-se à internet.
Segurança (aplicada no servidor): só administradores criam/alteram/apagam instrumentos e apagam histórico e transportes;
funcionários mudam estados, registam manutenções e transportes e só acrescentam ao histórico.
Nota: a base começa vazia. As fotos das faturas ficam dentro dos registos; muitas fotos tornam a primeira carga mais lenta.
