BMI online (partilhado entre todos) + instalável no telemóvel

Usa o Firebase (Google), que tem plano gratuito. Os nomes dos menus podem mudar: se algo não bater, siga a lógica.

1) console.firebase.google.com > Adicionar projecto (pode desligar o Google Analytics).
2) Authentication > Começar > activar "E-mail/palavra-passe". Em "Utilizadores", adicione cada pessoa (e-mail + palavra-passe).
   Em Authentication > Definições > Domínios autorizados, adicione SEU-UTILIZADOR.github.io
3) Firestore Database > Criar base de dados (modo de produção, escolha uma região).
4) Firestore > separador "Regras": apague tudo, cole o conteúdo de firestore.rules e publique.
5) Definições do projecto (roda dentada) > "As suas apps" > Web (</>) > registar a app > copie o firebaseConfig
   e cole os valores no ficheiro firebase-config.js (apiKey, authDomain, projectId, appId).
6) Administradores: em Authentication copie o UID do utilizador. Em Firestore, crie a colecção "admins" e um documento
   com ID = esse UID (pode ter qualquer campo, ex.: admin = true). Quem tem esse documento é administrador.
7) GitHub: no repositório, substitua os ficheiros por estes (Add file > Upload files) e faça Commit. O GitHub Pages actualiza em minutos.
8) Telemóvel: abra o link, entre com e-mail e palavra-passe e use "Adicionar ao ecrã inicial".
   Funciona offline depois da 1ª abertura com internet; as alterações sincronizam quando voltar a ligação.

Regras (firestore.rules): só administradores criam/alteram/apagam instrumentos; só administradores apagam histórico e transportes;
funcionários só acrescentam ao histórico. Estas regras são aplicadas no servidor.
Nota: os dados do site antigo (claude.ai) e do app offline não passam para esta base; começa vazia.
